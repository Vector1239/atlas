# Atlas

Open **Atlas** from **Applications** or Spotlight. The installed app is `/Applications/Atlas.app`.

Atlas brings your existing Germany-life project and Hermes Agent into one local Mac app:

- **Today:** weather, Mensa, news, deadlines, and a brief generated by Hermes.
- **Explore:** jobs and events together on an interactive map. Pan or zoom to browse the visible area, select a city pin, or use the Around Trier / Germany / Europe views. Switch between Everything, Jobs and Events; search both kinds and filter by radius, city, event dates and category. More filters keep job boards, saved/student roles, remote mentions, posting language, seniority and sorting available. Original job details, bookmarks, feedback and Ask Atlas are still included.
- **English headlines:** Today shows English headlines, with an original-headline toggle and per-headline originals. Existing translations are included locally; new headlines can be translated by local Qwen when it is already running.
- **Life admin:** add deadlines and work shifts; see the project's work-day budget.
- **Ask Atlas:** a persistent Hermes conversation powered by local Qwen.
- **Settings:** edit your profile, change reasoning effort, start or stop Qwen, manage routines, check sources, and install app updates.

The version (currently 1.3.0) is shown at the bottom of the sidebar and under **Atlas → About Atlas**. It is set in `app/package.json`; bump it there when you change the app.

## Updating Atlas

Open **Settings → Updates**, or **Atlas → Check for Updates…** in the Mac menu. Select **Check for updates**, then **Update & restart** when an update is available. Progress and errors appear in the app; the update log is available on the same page.

The updater fetches `main` from the private `Vector1239/atlas` repository and compares its commit with the installed build. It still detects an update if you have already pulled the source, or if a commit did not bump the version. Builds run in a temporary checkout; the app is signed locally, installed and restarted, with the previous app restored if the new app fails its startup check. Personal profiles, chats and other local data stay in place.

Keep the source clone at its configured location, with Node.js, Git and the GitHub CLI installed and signed in. Updates require the checkout to be on `main`, with no uncommitted source changes or diverged commits. The updater only fast-forwards the checkout; it does not discard or stash your work. Nothing is downloaded or installed until you use the update controls. Stop any active AI request before installing; Qwen’s paused/startup preference is preserved.

## First use

1. Open Atlas. Browse the Explore map with Qwen paused. Start it in **Settings → Local model** when you want AI features; the lower-left status changes to **Qwen is ready**.
2. In **Settings → Your profile**, replace the template placeholders and save.
3. Add your real deadlines in **Life admin**. The example dates are ignored.
4. Enable routines in **Settings → Routines**. They save results locally and run while Atlas is open and Qwen is ready.

Telegram is optional. No cloud model key is required for the installed configuration.

## Local model

Qwen3.8-27B Q4_K_M (16.81 GB), served by llama.cpp using Apple Metal, with a 65,536-token context and medium reasoning. Its published SHA-256 was verified after download.

The model lives in `~/.cache/Atlas/models/`. **Stop Qwen** appears at the top of every page while Qwen is active, including during a brief or reply. It cancels the active request, stops the model, frees memory, and remembers the pause across app restarts. The same action is in **Settings → Local model → Stop Qwen & free memory**. Starting Qwen enables automatic startup on subsequent launches until you stop it again. Quitting Atlas stops the model and app service it launched.

The current English job titles and headline translations are included locally. Unseen German titles remain clearly labelled in their original language until you select **Translate new titles** with Qwen running. Use **Translate new headlines** on Today for new headlines. Both translation actions require Qwen to already be running and never start it automatically. Translations are cached by their original text on your Mac. Translated titles do not establish English-only eligibility; check the original listing for requirements. Distances are supplied by job boards and are not driving distances; unknown distances are excluded when you set a radius.

Map pins use verified city centres from [Open-Meteo / GeoNames](https://open-meteo.com/en/docs/geocoding-api); they do not claim an exact employer or event address. Cities without a verified match stay unplaced; untick **Only this map area** to include those listings. City coordinates ship with the app; no profile or job description is sent to a geocoding service. Job radii use the board's distance from Trier; event radii use approximate straight-line distance between city centres. Neither is a travel-distance estimate.

The basemap uses [OpenStreetMap](https://www.openstreetmap.org/copyright) tiles under its [tile usage policy](https://operations.osmfoundation.org/policies/tiles/), with visible attribution and normal browser caching. Only visible tiles are requested, without bulk/offline downloads. Opening and moving the map contacts the tile provider with the requested tile area and normal connection information; it sends no Atlas profile, chat, job details or launch token. If tiles are unavailable, pins and listings still work.

Events remain a dated selection checked on 17 October 2026, not a comprehensive live event feed. Expired entries disappear, old date checks are flagged, and official calendars are linked below the map.

News, map tiles, weather, job sources, and links still need internet. Model inference runs locally.

## How it fits together

Atlas' React interface runs in an Electron Mac app. A Python service reads and updates project data and starts the local model. Chat calls the installed `hermes chat` command and uses real Hermes sessions, memory, skills, and Docker terminal tools. Atlas does not implement a replacement agent.

The app uses `germany-life-hermes` for your profile, deadlines, work log, and feedback. Keep that folder in place. `state/atlas.json` stores app chats and preferences; `state/atlas_snapshot.json` caches sources.

## Development

From a fresh clone, install the project scripts and skills using the [macOS setup guide](germany-life-hermes/SETUP-macOS.md). Hermes, Python 3.12, llama.cpp and Docker Desktop are separate prerequisites; the Qwen weights are downloaded separately and are not stored in Git.

From the repository root:

```bash
cd app
npm ci
npm run build
/opt/homebrew/bin/python3.12 backend.py
```

For a checkout outside `~/Projects/Atlas`, set `ATLAS_PROJECT` to the absolute path of its `germany-life-hermes` folder before starting the app or service. Run `npm start` from `app/` to open the desktop app, or `npm run package` to create an Apple Silicon app under `app/release/`. `npm run build` records the current Git commit in the ignored `app/build-info.json`, which is included in packaged apps for update checks.

For live reload while editing the interface, start the service with `backend.py --port 4317` (or set `ATLAS_PORT` to match), open the launch URL it prints once so the browser gets a session, then run `npm run dev` and open `http://127.0.0.1:4173`.

The service prints a local launch URL that establishes an app session. It listens only on loopback, requires a launch-session cookie for private endpoints, rejects outside origins, and exposes specific app actions. The renderer has no Node access.

Tests from the repository root:

```bash
python3.12 -m unittest discover -s app/tests -v
germany-life-hermes/gl test
node --test app/tests/*.test.js
```

The repository contains app source, tests, icons, project scripts, skills, templates and the npm lockfile. Personal profiles, chats, deadlines, work logs, launch tokens, logs, model weights, dependencies and build output are excluded. Your local data stays in place when cleaning or updating the source; `germany-life-hermes/install.sh` creates missing personal files from the checked-in templates.
